## 一、整改方案概述

### 1.1 问题根因

经过全面排查，确认 **Agent 执行层完全缺失**：
- OpenMOSS 是纯 REST API 服务，不包含 Agent 执行进程
- OpenClaw 中没有配置 executor/reviewer/patrol 角色的 Agent
- OpenClaw Cron 为空（`No cron jobs.`）
- `task-cli.py` 的 BASE_URL 硬编码为 `192.168.31.128:6565`，Docker 环境无法使用

### 1.2 整改方案

按 OpenMOSS 官方设计，通过 OpenClaw 创建 Agent 并配置 cron 定时唤醒：

| 任务编号 | 任务名称 | 工作内容 | 预计工时 |
|---------|---------|---------|---------|
| MVP-04-T03-01 | 修改 task-cli.py BASE_URL | 改为环境变量 `OPENMOSS_BASE_URL` | 1h |
| MVP-04-T03-02 | 在 OpenClaw 中创建 Executor Agent | 使用 `openclaw agent create` 创建，配置提示词 | 2h |
| MVP-04-T03-03 | 在 OpenClaw 中创建 Reviewer Agent | 使用 `openclaw agent create` 创建，配置提示词 | 2h |
| MVP-04-T03-04 | 在 OpenClaw 中创建 Patrol Agent | 使用 `openclaw agent create` 创建，配置提示词 | 2h |
| MVP-04-T03-05 | 配置 OpenClaw Cron 定时任务 | executor 10min, reviewer 15min, patrol 30min | 2h |
| MVP-04-T03-06 | 向 OpenMOSS 注册 Agent | 调用 register API 获取 API Key | 1h |
| MVP-04-T03-07 | 端到端测试验证 | 验证完整执行链路 | 3h |

**总计**: 13h
