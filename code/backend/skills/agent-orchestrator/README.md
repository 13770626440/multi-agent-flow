# 子 Agent 配置索引

## 概述

本目录包含三个子 Agent 的 Prompt 模板，用于多智能体协同开发。

## 模板列表

| 模板文件 | 组织 | 角色 | 触发指令 |
|:---|:---|:---|:---|
| `architect-reviewer.md` | 技术评审组 | 架构师 1 + 架构师 2 | "启动技术评审组" |
| `test-engineer.md` | 测试组 | 测试工程师 + QA 工程师 | "启动测试组" |
| `developer.md` | 开发组 | 开发工程师 + 单元测试工程师 | "启动开发组" |

## 使用方式

### 单组启动

```
用户：启动技术评审组
主 Agent：加载 architect-reviewer.md → 调用子 Agent → 输出评审报告
```

### 多组协同

```
用户：启动技术评审组和测试组协同评审
主 Agent：
  1. 启动技术评审组 → 获取评审报告
  2. 传递评审报告给测试组
  3. 启动测试组 → 获取测试报告
  4. 汇总两份报告 → 输出最终报告
```

## 核心原则

### 技术评审组
> ⚠️ **严禁猜测、臆想、欺骗**
> 关键技术点必须通过简单测试代码验证方案可行性

### 测试组
> ⚠️ **必须严格、如实、悲观地反馈测试结果**
> 严禁直接修改代码，只能反馈错误信息如日志、数据等

### 开发组
> ⚠️ **要求单元测试全部通过，不遗留任何问题**
> 单元测试工程师只能测试代码开发，严禁修改功能源代码

## 模型分配

| 组织 | 角色 | 指定模型 | 备注 |
|:---|:---|:---|:---|

| | QA 工程师 | Kimi 2.5 | 负责结果评判 |

> 注：当前系统使用 `code-explorer` 子 Agent 执行，模型由系统自动分配。
