## MVP定义

### MVP目标

通过最小可行产品验证核心架构可行性，包含以下4个核心目标：

| 目标 | 说明 | 验收标准 |
|------|------|---------|
| **1. Agent对话完整流程** | 通过OpenClaw Agent对话完成创建任务、执行、派发、评审、结果反馈 | 用户通过自然语言对话可完成完整任务生命周期 |
| **2. 三组件打通** | Backend/OpenMOSS/OpenClaw严格按分工完成完整任务执行 | 三组件各司其职，数据流清晰，无职责交叉 |
| **3. 固定+动态任务验证** | 简单任务包含固定任务与动态任务分解，OpenMOSS Dashboard展示 | 固定任务按模板执行，动态任务按需分解，Dashboard可见 |
| **4. 通用Docker配置** | OpenClaw版本与knowledge-base一致（2026.4.9），抽取通用配置 | 两个项目可复用同一套Docker配置 |

### MVP范围

**包含**：
- Backend核心模块（模板管理、任务管理、派发引擎、OpenMOSSClient、OpenClawClient）
- OpenMOSS部署与配置（Agent注册、任务队列、审查流程）
- OpenClaw部署与配置（Gateway、Agent对话、Skill绑定）
- 简单任务验证流程（固定任务+动态任务分解）
- OpenMOSS Dashboard展示

**不包含**：
- 完整Dashboard前端（Vue3）
- 自然语言意图识别（硬编码路由）
- 高级功能（并行执行、部分通过、性能分析）
- 安全基础设施（JWT、RBAC延后）

## 工作规则

### 规则0：任务执行流程

**每个任务项必须严格按以下7步流程执行，不允许跳步或并行**：

| 步骤 | 阶段 | 执行内容 | 负责人 | 完成标准 |
|------|------|---------|--------|---------|
| **1** | 介绍阶段 | AI详细介绍当前任务的目的、实现逻辑、技术方案 | AI助手 | 用户理解 |
| **2** | 确认阶段 | 用户理解描述，提出疑问，AI负责解释、整改 | 用户+AI | 用户确认无疑问 |
| **3** | 评审阶段 | AI主动启动架构组技术评审，循环评审直到打分≥9分且P0/P1问题整改通过 | 架构组（2名架构师） | 评分≥9分，P0/P1问题全部解决 |
| **4** | 开发阶段 | 用户确认方案后，启动开发组完成工作并完成单元测试，**将单元测试用例及执行结果补充到04-详细设计文档中** | 开发组（开发+单元测试工程师） | 代码完成，单元测试全部通过，**测试用例及结果已记录到04-详细设计文档** |
| **5** | 测试阶段 | 启动测试组，对当前功能模块所有设计内容全覆盖测试。**测试组红线：严禁修改代码，只能记录错误现象、错误日志数据等。错误必须由开发组完成修改。** | 测试组（测试员+QA） | 测试用例全覆盖，测试结果如实反馈，**无代码修改** |
| **6** | 确认阶段 | 用户确认模块结束 | 用户 | 用户确认通过 |
| **7** | 流转阶段 | 用户确认后方可进入下一个模块，否则不继续进展 | 用户 | 用户明确指示进入下一模块 |

**关键规则**：
- **循环评审**：步骤3为循环评审，每次评审后必须根据意见整改，再次评审，直到评分≥9分
- **P0/P1问题**：评审中发现的P0/P1问题必须全部整改通过，否则不能进入下一阶段
- **用户确认**：步骤2、4、6、7都需要用户明确确认，AI不得自行推进
- **不跳步**：必须按顺序执行，不允许跳过任何步骤
- **不并行**：当前模块未完成前，不开始下一个模块

## MVP-02-T07 设计方案调整记录（2026-04-24 11:30）

### 调整原因

**发现设计错误**：原方案中 Decomposer 直接调用 LLM 进行任务分解，违反系统架构原则。

**正确设计**：系统不直接调用 LLM，所有任务（包括任务分解）都应通过 OpenMOSS 启动 Agent 完成。

### 变更对比

| 维度 | 原方案（错误） | 新方案（正确） |
|:---|:---|:---|
| **任务分解执行者** | Backend 直接调用 LLM | OpenMOSS 调度 Agent 执行 |
| **Decomposer 职责** | 调用 LLM → 解析 JSON → 校验 | 创建 OpenMOSS 任务 → 等待完成 → 解析结果 |
| **异步等待机制** | 同步等待 LLM 返回 | 异步等待 Agent 完成（可能数分钟） |
| **错误处理** | LLM 超时/格式错误 | Agent 超时/失败/返回非 JSON |
