### 1. 设计目标

注册 planner、executor、reviewer、patrol 角色到 OpenMOSS，获取 API Key 并自动写入 `.env` 文件。

### 2. 核心设计

**文件**：`scripts/register_agents.py`

**功能特性**：
- 调用 `POST /api/agents/register` 注册 Agent
- 幂等性处理：捕获 400 错误，识别已存在 Agent
- 重试机制：网络波动自动重试 3 次（指数退避）
- CLI 参数：`--dry-run`（仅验证）、`--force`（强制重新注册）

**代码片段**：
```python
# 注册 Agent（带重试）
response = await client.post(
    f"{OPENMOSS_BASE_URL}/api/agents/register",
    headers={"X-Registration-Token": REGISTRATION_TOKEN},
    json={"name": name, "role": role, "description": description}
)

# 幂等性处理
if response.status_code == 400 and "exists" in response.text.lower():
    print(f"⚠️  Agent 已存在：{name}")
```
