### 1. 设计目标

创建 `multi-agent-flow-manager` Skill，使 OpenClaw Agent 能够识别并处理任务管理相关的自然语言指令（如创建任务、查询进度）。

### 2. 核心设计

**文件**：`code/backend/skills/multi-agent-flow-manager/SKILL.md`

**功能特性**：
- **意图识别**：支持创建任务、查询进度、控制任务、查询模板。
- **参数定义**：明确每个意图的必填/选填参数。
- **API 调用**：指示 Agent 使用 `requests` 库调用 Backend API。
- **鉴权机制**：采用“尽力而为”模式，若环境变量存在 Token 则携带，否则不携带。
- **错误处理**：定义了 API 异常、参数缺失、权限不足等情况的回复策略。
