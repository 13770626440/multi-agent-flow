**问题链：**

1. MAF Backend 的 `SubTaskCreateRequest` 需要字段：`name` + `role` + `instruction`
2. OpenMOSS 的 `SubTaskCreateRequest` 需要字段：`task_id` + `name` + `description` + `deliverable` + `acceptance`
3. MAF Backend 收到请求后，**直接将原始字段转发给 OpenMOSS**，未做字段映射转换

5. MAF Backend 捕获到 OpenMOSS 的错误 → 整个子任务创建回滚（本地数据库也未写入）

**期望的正确映射应该是：**
| MAF Backend 字段 | OpenMOSS 字段 |

| `name` | `name` |
| `role` | `assigned_agent` |
| `instruction` | `description` |
| — | `task_id`（从 URL path 注入） |
| — | `deliverable` / `acceptance` / `priority`（需补充） |
