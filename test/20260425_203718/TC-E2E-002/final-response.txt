## ⚠️ 发现问题

**maf-backend 存在两个 Bug：**

1. **子任务创建失败** — 后端调用 `POST /api/v1/tasks/{id}/sub-tasks` 时，返回 `400 Bad Request`。根因是后端的 `SubTaskCreateRequest` schema（字段：`name, role, instruction`）与 OpenMOSS 的 `SubTaskCreateRequest` schema（字段：`task_id, name, description, deliverable...`）不匹配，后端未做正确的字段映射转换。

2. **模板实例化失败** — 调用 `POST /api/v1/templates/simple-dev-flow/instantiate` 返回 `500 Internal Server Error`，导致无法通过模板自动创建子任务。

我通过直接操作 OpenMOSS API 绕过了这两个 Bug，成功创建了任务与子任务。建议后续修复后端与 OpenMOSS 的 schema 映射问题。
